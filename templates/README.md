# 拾味山房 · 餐馆首页

一个纯前端、无框架的单页餐馆官网首页，双击即可打开。

## 文件结构

```text
codex-shop/
├─ index.html      # 页面结构
├─ css/style.css   # 全部样式与响应式布局
├─ js/main.js      # 导航、轮播、表单校验、滚动动画
└─ README.md
```

## 本地预览

直接双击 `index.html`，或在项目目录启动本地静态服务：

```bash
python -m http.server 8000
```

然后浏览器访问 `http://localhost:8000`。

## 页面内容

- 吸顶导航 + 移动端汉堡菜单
- 首屏 Hero 与快捷信息卡
- 品牌故事 + 数据亮点
- 招牌菜卡片（6 道示例菜）
- 餐厅环境画廊
- 食客点评轮播（自动播放 + 手势/按钮切换）
- 在线预订表单（前端校验 + 模拟提交）
- 页脚联系方式

## 修改提示

- 店名、地址、电话、文案均为示例，直接在 `index.html` 中全局搜索替换即可。
- 菜品图片使用 Unsplash 公开图（按 `?w=` 参数自适应尺寸）。
- 图片加载失败时会自动显示渐变色块 + 图标占位，不影响整体布局；如需离线使用，可将图片下载到本地 `img/` 目录并替换 `src`。
